# claude.ai 설정 — 공부하던 채팅에서 바로 기록 뽑기

목표: 공부하던 claude.ai 채팅 **그 자리에서** "오늘 하루치 공부한 내용 기록 남겨줘!" 한 마디로,
트래커의 **⤓ 오늘 기록 붙여넣기** 에 그대로 붙여넣을 텍스트가 나오게 하는 것.

## 왜 프로젝트 지침만으로는 부족한가

claude.ai 의 프로젝트 지침·프로젝트 지식·메모리는 **그 프로젝트 안의 채팅에만** 적용된다.
메모리도 프로젝트마다, 프로젝트 밖 채팅과도 따로 관리된다. 그래서 형식을 '트래커용 프로젝트'에만
넣어 두면, 공부는 다른 채팅에서 하고 기록은 그 프로젝트에서 뽑아야 한다. 그러면 그 채팅은 공부한
대화를 모르니 요약을 복사해 옮겨야 하고, 그 과정에서 맥락이 빠진다.

**스킬(Skill)** 은 계정에 한 번 올려 두면 프로젝트 안팎 **모든 채팅**에서 쓸 수 있다.
그래서 형식은 스킬에 넣고, 메모리에는 짧은 사실(트래커의 과목·블록 이름)만 둔다.

| 무엇을 | 어디에 | 이유 |
|---|---|---|
| 기록 형식과 규칙 (긴 글) | **스킬** `learning-tracker-record` | 모든 채팅에서 동작, 내용이 요약되지 않고 그대로 읽힌다 |
| 트래커의 과목·블록 이름 (짧은 사실) | **메모리** (또는 요청할 때 직접 말하기) | 이름이 바뀔 때 "기억해" 한 마디로 고칠 수 있다 |

> claude.ai 의 메뉴 이름과 위치는 바뀔 수 있다. 아래는 2026년 10월 기준
> [Anthropic 도움말](https://support.claude.com/en/articles/12512180-use-skills-in-claude)을 따랐다.

## 1. 스킬 올리기 (한 번)

1. **설정 → Capabilities** 에서 **Code execution and file creation** 을 켠다. (스킬이 동작하는 조건이다)
2. [`claude-skill/learning-tracker-record.zip`](claude-skill/learning-tracker-record.zip) 을 받는다.
   (GitHub 에서 파일을 열고 다운로드 버튼)
3. **Customize → Skills → + → Create skill → Upload a skill** 에서 zip 을 올린다.

스킬 내용은 [`claude-skill/learning-tracker-record/SKILL.md`](claude-skill/learning-tracker-record/SKILL.md) 에서
읽어 볼 수 있다. 형식을 고치면 이 파일을 고치고 zip 을 다시 만들어 다시 올린다.

### 스킬이 하는 일

- "오늘 하루치 공부한 내용 기록 남겨줘", "트래커 기록 남겨줘" 같은 요청에 반응한다
  (확실히 하려면 "learning-tracker-record 스킬로 오늘 기록 남겨줘").
- 이 대화에서 오늘 나눈 내용으로 블록마다 `---ENTRY---` + `---BLOCK---` 를 만든다.
  내용은 '오늘 한 것 / 배운 점 / 헷갈렸던 부분 정리(표)' 세 절.
- 전체를 코드블록 하나로 감싸 준다 → 코드블록의 **복사 버튼** 한 번으로 통째로 복사.
  (코드블록 펜스까지 같이 복사돼도 트래커가 알아서 걷어낸다)
- 과목·블록 이름이나 오늘 날짜를 모르면 지어내지 않고 먼저 묻는다.
- BLOCK 에는 **아는 항목만** 적는다. 이 채팅은 트래커에 저장된 다이어그램·SVG 를 본 적이 없으므로,
  모르면 아예 적지 않는다 → 트래커가 기존 값을 그대로 둔다 (아래 'BLOCK 규칙').

## 2. 트래커 이름을 메모리에 넣기 (과목마다 한 번, 블록이 늘면 다시)

트래커는 **과목을 자동으로 만들지 않고**, 블록 이름이 다르면 **새 블록을 만든다.**
그래서 claude.ai 가 트래커의 이름을 글자 그대로 알아야 한다.

공부하는 채팅(또는 그 채팅이 속한 프로젝트의 채팅)에서 이렇게 말한다.

```
기억해: 학습 트래커의 과목 '통계'의 블록 이름은 Week 0, Week 1, Week 2, … Week 10 이야.
트래커 기록을 뽑을 때 이 이름을 글자 그대로 써.
```

- 블록 목록은 트래커 과목 화면의 **과목 정보 내보내기** 로 복사하면 정확하다.
- 메모리는 **프로젝트마다 따로**다. 공부를 프로젝트 안에서 한다면 그 프로젝트의 채팅에서,
  프로젝트 밖 일반 채팅에서 한다면 일반 채팅에서 말해야 그쪽 메모리에 들어간다.
- 저장된 내용은 **설정 → Memory** 에서 확인·수정할 수 있다.
- 메모리를 안 쓰고 싶으면 요청할 때 이름을 같이 말해도 된다: "통계 Week 5로 오늘 기록 남겨줘".

## 3. 매일

1. 공부하던 채팅에서: **"오늘 하루치 공부한 내용 기록 남겨줘!"**
2. 답의 코드블록 복사 버튼 → 트래커 홈 **⤓ 오늘 기록 붙여넣기** → **읽기** → **반영**.

## BLOCK 규칙 — 적은 항목만 바뀐다

| BLOCK 에 쓴 것 | 트래커가 하는 일 |
|---|---|
| `설명:` 등 항목을 적음 | 그 값으로 바꾼다 |
| 항목을 아예 안 적음 | **지금 값을 그대로 둔다** |
| `다이어그램: (지움)` | 그 항목을 비운다 |

`설명`(필수)은 이 블록 전체의 누적 요약 — 지금 어디까지 했고 다음은 무엇인지.
`진행률`은 방금 만든 ENTRY 의 진행률과 같은 값. 다이어그램의 단계 문구('정독 중' → '완료')는
그 채팅에 현재 다이어그램 원문이 있을 때만 고쳐서 **전체를** 다시 적는다. 원문이 필요하면
트래커 블록 화면의 **⟳ 블록 정보가 기록보다 오래됨** (또는 블록 정보 내보내기)으로 복사한 텍스트를
채팅에 붙여넣고 "블록 정보 갱신해줘"라고 하면 된다.

## 트래커가 미리보기에서 짚어 주는 것

| 미리보기 | 원인 | 결과 |
|---|---|---|
| 오류: 과목이 없습니다 | 과목 이름이 트래커와 다름 | **멈춤.** 과목은 자동으로 만들지 않는다 |
| 새로 생성됨: 과목 / 블록 | 블록 이름이 트래커와 다름 (또는 정말 새 블록) | 오타면 취소하고 이름을 고친다 |
| 맞춰 읽었습니다 | 공백·대소문자만 다름 | 같은 것으로 읽었다 |
| 블록 정보(---BLOCK---)가 없습니다 | BLOCK 을 안 냄 | 기록만 들어가고 블록 정보는 그대로 |
| 블록 정보에 진행률이 없어 그대로 둡니다 | BLOCK 에 진행률을 안 적음 | 블록 화면 숫자는 어차피 최근 기록 값으로 보인다 |
| 블록 정보의 진행률이 기록의 진행률과 다릅니다 | 진행률 규칙을 어김 | 블록 진행률은 BLOCK 값으로 저장된다 |
| '(지움)'으로 적어 ○○이 지워집니다 | BLOCK 이 항목을 비우라고 함 | 반영하면 지워진다 |
| 이름이 기록과 글자가 다릅니다 | BLOCK 과 ENTRY 의 이름이 다름 | 같은 블록으로 읽었다 |
| 기록 날짜가 오늘이 아닙니다 | 날짜를 잘못 앎 (또는 어제 공부를 오늘 기록) | 맞는지 확인한다 |

## 스킬을 쓸 수 없을 때

Code execution 을 켤 수 없는 환경이라면 차선책:

- **프로젝트 지침**: 공부를 늘 같은 프로젝트에서 한다면 `SKILL.md` 의 본문(맨 위 `---` 머리말 아래 전부)을
  그 프로젝트의 지침(Project instructions)에 붙여넣는다. 그 프로젝트의 채팅에서만 동작한다.
- **개인 선호(Personal preferences)**: 모든 채팅에 적용되지만, 여기에 긴 형식을 다 넣는 것은 권하지 않는다.
  다른 대화의 답에도 영향을 주고, 길이 제한이 있을 수 있다(확인하지 못했다).
- **메모리에 형식 저장**: "기억해"로 형식을 넣을 수는 있지만, 메모리는 주제별로 요약해 보관되므로
  표 모양이나 마커 같은 세부가 그대로 지켜진다는 보장이 없다. 이름 같은 짧은 사실에만 쓴다.
