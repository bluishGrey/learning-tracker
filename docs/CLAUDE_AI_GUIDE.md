# claude.ai 지침 — 블록 정보 동기화

학습 트래커로 가져올 기록을 claude.ai 에서 만들 때 쓰는 지침이다.
아래 **"붙여넣을 지침"** 상자 안의 내용을 claude.ai 프로젝트의 지침(Project instructions)에
그대로 붙여넣는다. 트래커 코드가 이 지침을 대신 지켜 줄 수는 없다. 트래커가 하는 일은
붙여넣은 결과를 읽고, 규칙에서 어긋난 부분을 가져오기 미리보기에 경고로 띄우는 것까지다.

형식 자체(필드 이름, 필수 항목, 읽는 규칙)는 [README 의 'claude.ai 와 주고받기'](../README.md#claudeai-와-주고받기)가
기준이고, 코드 기준은 `src/lib/structuredText.js` 다.

---

## 붙여넣을 지침

````text
## 학습 트래커 출력 규칙 — 블록 정보 동기화

학습 기록을 정리할 때마다 아래 규칙을 지킨다.

1. ---ENTRY--- 문서 바로 뒤에, 그 기록이 속한 블록의 ---BLOCK--- 문서를 같은 답변에 출력한다.
   요청하지 않아도 항상 낸다.
2. 트래커는 BLOCK 문서에서 빠진 항목을 지운다. 그래서 바뀐 게 없어도
   설명·진행률·다이어그램·SVG 를 항상 전부 다시 적는다. (지금 값이 있는 항목은 하나도 빼지 않는다)
3. BLOCK 의 과목·블록 이름은 ENTRY 와 글자 하나까지 똑같이 쓴다.
   한 번에 한 블록의 BLOCK 만 낸다.
4. BLOCK 의 진행률은 방금 만든 ENTRY 의 진행률과 같은 값으로 쓴다.
5. 설명은 누적 요약으로 갱신한다: 현재 어디까지 했고, 다음에 할 것이 무엇인지.
6. 다이어그램의 단계 문구(예: '정독 중' → '완료')를 현재 상태에 맞게 바꾼다.

출력 모양:

---ENTRY---
날짜: YYYY-MM-DD
과목: (과목 이름)
블록: (블록 이름)
제목: (기록 제목)
태그: 태그1, 태그2

내용:
(마크다운 본문)

진행률: (0~100 숫자)
---END---

---BLOCK---
과목: (ENTRY 와 똑같은 과목 이름)
블록: (ENTRY 와 똑같은 블록 이름)

설명:
(누적 요약 — 지금 어디까지 했고 다음은 무엇인지)

진행률: (ENTRY 와 같은 숫자)

다이어그램:
```mermaid
(단계 문구를 현재 상태로 바꾼 전체 다이어그램)
```

SVG:
(지금 SVG 가 있으면 전체 원문을 그대로)
---END---
````

## 트래커에서 붙여넣는 곳

ENTRY 와 BLOCK 을 **한꺼번에** 복사해서 붙여넣는다. 순서는 상관없다.

| 붙여넣는 곳 | 블록 정보가 반영되는 시점 |
|---|---|
| 새 기록(또는 기록 수정) → **⤓ 기록 가져오기** | 폼을 채운 뒤 **기록을 저장할 때** (폼 위 안내에서 '반영 안 함'을 고를 수 있다) |
| 블록 화면 → **기록 전체 가져오기** | 미리보기에서 **기록 반영**을 누를 때 |

읽기를 누르면 미리보기에 "'OO' 블록의 설명 · 진행률 · 다이어그램이 바뀝니다"와 항목별
전/후 요약이 나온다. 규칙에서 어긋나면 반영 전에 경고가 뜬다 (막지는 않는다).

| 경고 | 원인 (어긴 규칙) |
|---|---|
| 블록 정보(---BLOCK---)가 없습니다 | 1번. 블록 정보는 그대로 두고 기록만 가져온다 |
| 지금 있는 다이어그램/SVG/진행률이 지워집니다 | 2번. BLOCK 에 그 항목이 빠졌다 |
| 이름이 기록과 글자가 다릅니다 | 3번. 공백·대소문자를 무시하고 같은 블록으로 읽기는 했다 |
| 다른 블록의 블록 정보 / 블록 정보가 2개 | 3번. 이 경우는 오류로 멈춘다 |
| 블록 정보의 진행률이 기록의 진행률과 다릅니다 · 진행률이 없어 지워집니다 | 4번 |

5·6번(설명 요약, 다이어그램 문구)은 내용의 문제라 트래커가 검사하지 않는다.
미리보기의 전/후 요약을 보고 판단한다.

## 블록 정보가 이미 낡았을 때

블록 화면 상단이나 사이드바에 '블록 정보가 기록보다 오래됨'(⟳)이 떠 있으면 그 표시를 누른다.
같은 규칙(이름은 글자까지 같게, 진행률은 최근 기록과 같은 값, 설명은 누적 요약,
다이어그램 단계 문구 갱신, 전 항목 다시 적기)이 담긴 갱신 요청문이 클립보드에 복사된다.
claude.ai 에 붙여넣고, 받은 ---BLOCK--- 는 블록 화면의 **블록 정보 가져오기**로 붙여넣는다.
