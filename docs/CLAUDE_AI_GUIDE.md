# claude.ai 지침 — 오늘 기록 내보내기

공부하던 claude.ai 채팅에서 **"오늘 하루치 공부한 내용 기록 남겨줘!"** 라고 하면,
트래커의 **⤓ 오늘 기록 붙여넣기** 에 그대로 붙여넣을 수 있는 텍스트가 나오게 하는 지침이다.

아래 **"붙여넣을 지침"** 상자 안의 내용을 그 과목의 claude.ai 프로젝트 지침(Project instructions)에
붙여넣는다. 트래커 코드는 claude.ai 의 답을 바꿀 수 없다. 트래커가 하는 일은 붙여넣은 결과를 읽고,
지침에서 어긋난 부분을 미리보기에서 경고하는 것까지다.

사용자 입장의 전체 흐름은 [USER_GUIDE.md](USER_GUIDE.md), 형식의 세부 규칙은
[README 의 'claude.ai 와 주고받기'](../README.md#claudeai-와-주고받기)에 있다.

---

## 준비: 트래커의 이름을 claude.ai 에 알려 주기

트래커는 과목을 **자동으로 만들지 않고**, 블록은 이름이 안 맞으면 **새로 만든다.**
그래서 claude.ai 가 트래커에 있는 과목·블록 이름을 정확히 알아야 한다.

1. 트래커의 과목 화면 → **과목 정보 내보내기** (과목 이름과 블록 목록이 복사된다)
2. claude.ai 프로젝트의 지식(Project knowledge)에 붙여넣는다.

블록을 새로 만들었으면(다음 주차로 넘어갔을 때 등) 이 과정을 한 번 더 하면 된다.

---

## 붙여넣을 지침

````text
## 학습 트래커 기록 규칙

내가 "오늘 하루치 공부한 내용 기록 남겨줘"처럼 오늘 공부를 기록해 달라고 하면,
이 채팅에서 오늘 나눈 질문과 답을 정리해 아래 형식으로만 답한다.

### 무엇을 내나
- 오늘 공부한 블록마다 ---ENTRY--- 하나, 그 바로 뒤에 같은 블록의 ---BLOCK--- 하나.
  보통은 한 쌍이고, 오늘 두 블록을 공부했으면 두 쌍을 낸다.
- 요청하지 않아도 BLOCK 은 항상 낸다.
- 형식 앞뒤에 인사말이나 설명을 붙여도 되지만, 문서 안쪽에는 형식 외의 문장을 넣지 않는다.

### 이름
- 과목·블록 이름은 프로젝트 지식에 있는 트래커의 '과목 정보'에 적힌 이름을 글자 하나까지 그대로 쓴다.
- BLOCK 의 과목·블록 이름은 바로 앞 ENTRY 와 글자 하나까지 같게 쓴다.
- 목록에 없는 새 블록을 시작한 경우에만 새 이름을 쓰고, 답 끝에 "새 블록: 이름"이라고 한 줄 알린다.

### ENTRY
- 날짜: 오늘 날짜(YYYY-MM-DD). 오늘 날짜를 확실히 모르면 답하기 전에 나에게 묻는다.
- 제목: 오늘 공부를 한 줄로 (40자 이내).
- 태그: 쉼표로 구분, 2~5개.
- 내용: 마크다운. 아래 세 절을 이 순서로 쓴다.
  - `## 오늘 한 것` — 다룬 범위를 목록으로
  - `## 배운 점` — 새로 이해한 것을 목록으로
  - `## 헷갈렸던 부분 정리` — 아래 모양의 표. 오늘 헷갈렸던 것이 없으면 이 절을 빼도 된다.

    | # | 헷갈린 것 | 정답 요약 | 키워드 |
    |---|---|---|---|
    | 1 | (내가 헷갈렸던 질문이나 오해) | (한두 문장 정답) | (쉼표로 구분) |

- 내용 안에서는 줄 맨 앞에 "진행률:", "다이어그램:", "SVG:", "날짜:", "과목:", "블록:", "제목:", "태그:"로
  시작하는 줄을 쓰지 않는다 (트래커가 항목 이름으로 읽는다).
- 진행률: 이 블록을 어디까지 했는지 0~100 숫자.

### BLOCK (블록 정보 동기화)
- 트래커는 BLOCK 에서 빠진 항목을 지운다. 바뀐 게 없어도 설명·진행률·다이어그램·SVG 를
  항상 전부 다시 적는다. (지금 값이 있는 항목은 하나도 빼지 않는다)
- 진행률은 방금 만든 ENTRY 의 진행률과 같은 값으로 쓴다.
- 설명은 누적 요약으로 갱신한다: 현재 어디까지 했고, 다음에 할 것이 무엇인지.
- 다이어그램의 단계 문구(예: '정독 중' → '완료')를 현재 상태에 맞게 바꾼다.
- 한 번에 한 블록의 BLOCK 만 낸다 (블록이 둘이면 ENTRY 뒤마다 하나씩).

### 출력 모양

---ENTRY---
날짜: 2026-10-03
과목: (트래커의 과목 이름)
블록: (트래커의 블록 이름)
제목: (한 줄 제목)
태그: 태그1, 태그2

내용:
## 오늘 한 것
- …

## 배운 점
- …

## 헷갈렸던 부분 정리
| # | 헷갈린 것 | 정답 요약 | 키워드 |
|---|---|---|---|
| 1 | … | … | … |

진행률: 60
---END---

---BLOCK---
과목: (ENTRY 와 똑같이)
블록: (ENTRY 와 똑같이)

설명:
(누적 요약 — 지금 어디까지 했고 다음은 무엇인지)

진행률: 60

다이어그램:
```mermaid
(단계 문구를 현재 상태로 바꾼 전체 다이어그램)
```

SVG:
(지금 SVG 가 있으면 전체 원문을 그대로)
---END---
````

## 트래커가 미리보기에서 짚어 주는 것

**⤓ 오늘 기록 붙여넣기** 에서 읽기를 누르면, 지침에서 어긋난 부분을 반영하기 전에 보여준다.

| 미리보기 | 원인 | 결과 |
|---|---|---|
| 오류: 과목이 없습니다 | 과목 이름이 트래커와 다름 | **멈춤.** 과목은 자동으로 만들지 않는다 |
| 새로 생성됨: 과목 / 블록 | 블록 이름이 트래커와 다름 (또는 정말 새 블록) | 오타면 취소하고 이름을 고친다 |
| 맞춰 읽었습니다 | 공백·대소문자만 다름 | 같은 것으로 읽었다 |
| 블록 정보(---BLOCK---)가 없습니다 | BLOCK 을 안 냄 | 기록만 들어가고 블록 정보는 그대로 |
| 지금 있는 다이어그램/SVG/진행률이 지워집니다 | BLOCK 에 그 항목이 빠짐 | 반영하면 지워진다 |
| 이름이 기록과 글자가 다릅니다 | BLOCK 과 ENTRY 의 이름이 다름 | 같은 블록으로 읽었다 |
| 블록 정보의 진행률이 기록의 진행률과 다릅니다 | 진행률 규칙을 어김 | 블록 진행률은 BLOCK 값으로 저장된다 (화면 표시는 최근 기록 값) |
| 기록 날짜가 오늘이 아닙니다 | 날짜를 잘못 앎 (또는 어제 공부를 오늘 기록) | 맞는지 확인한다 |

설명의 질(누적 요약인지), 다이어그램 문구는 내용의 문제라 트래커가 검사하지 않는다.
미리보기의 블록 정보 전/후 요약을 보고 판단한다.

## 블록 정보가 낡았을 때

블록 화면 상단이나 사이드바 블록 옆에 '블록 정보가 기록보다 오래됨'(⟳)이 떠 있으면 그 표시를 누른다.
같은 규칙이 담긴 갱신 요청문이 클립보드에 복사된다. claude.ai 에 붙여넣고, 받은 ---BLOCK--- 를
**⤓ 오늘 기록 붙여넣기** 나 블록 화면의 **블록 정보 가져오기** 로 붙여넣는다.
