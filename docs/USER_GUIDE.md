# 학습 트래커 사용 설명서

**주소 → https://bluishgrey.github.io/learning-tracker/**

claude.ai 와 공부하며 쌓인 내용(배운 점, 헷갈렸던 것)을 날짜별·과목별로 보관하고
다시 꺼내 보는 도구다. 기록은 claude.ai 가 정리하고, 트래커는 그 텍스트를 붙여넣어 보관한다.

---

## 하루 흐름

평소에는 이 세 단계가 전부다.

| | 어디서 | 무엇을 |
|---|---|---|
| 1 | claude.ai (공부하던 그 채팅) | **"오늘 하루치 공부한 내용 기록 남겨줘!"** 라고 요청하고, 답을 통째로 복사한다 |
| 2 | 트래커 홈 | **⤓ 오늘 기록 붙여넣기** → 붙여넣기 → **읽기** → 미리보기 확인 → **반영** |
| 3 | 트래커 상단 | 공용 PC라면 끝내기 전에 **⬇ 내보내기** (아래 [공용 PC에서 쓸 때](#공용-pc에서-쓸-때)) |

2번에서 일어나는 일:

- 기록이 그 과목·블록에 들어가고, 캘린더의 오늘 칸에 제목이 생긴다.
- 블록 정보(설명·진행률·다이어그램)도 claude.ai 가 보낸 값으로 갱신된다. 보내지 않은 항목(대개 다이어그램)은 그대로 남는다.
- 같은 텍스트를 두 번 붙여넣어도 기록이 두 개가 되지 않는다 (같은 날짜·제목이면 갱신).
- 오늘 두 블록, 두 과목을 공부했어도 한 번에 붙여넣으면 된다.

> 1번이 이 형식으로 나오려면 claude.ai 에 스킬을 한 번 올려 둬야 한다 → [처음 한 번](#처음-한-번).
> 스킬은 프로젝트 안팎 어느 채팅에서든 동작하므로, **공부하던 채팅 그 자리에서** 바로 뽑으면 된다.
> 요약을 다른 채팅으로 옮길 필요가 없어서 그날 대화의 맥락이 그대로 기록에 남는다.

## 처음 한 번

### 과목과 블록 만들기

트래커는 **과목을 자동으로 만들지 않는다** (오타 하나로 과목이 둘로 갈라지는 걸 막기 위해서다).

1. 사이드바의 **과목** → 과목 추가 (예: 통계)
2. 과목 화면 → **과목 정보 가져오기** 에 블록 목록을 붙여넣으면 블록(진도 단위)이 한 번에 생긴다.

   ```
   ---SUBJECT---
   과목: 통계
   마감: 2026-12-20

   설명:
   기초 통계 입문

   블록 목록:
   Week 0
   Week 1
   Week 2
   ---END---
   ```

   블록은 '3주차', '1장' 같은 진도 단위다. 과목 진도율은 **완료한 블록 수 ÷ 전체 블록 수**로 계산된다.
   `과목` 말고는 전부 선택이다. **적힌 항목만 바뀌고** 적지 않은 설명·마감·다이어그램·SVG 는 그대로 남는다.
   (블록 목록을 적지 않으면 블록도 그대로다)

### claude.ai 에 스킬과 이름 넣기

자세한 순서는 [CLAUDE_AI_GUIDE.md](CLAUDE_AI_GUIDE.md). 요약하면:

1. claude.ai **설정 → Capabilities** 에서 Code execution 을 켜고,
   [`learning-tracker-record.zip`](claude-skill/learning-tracker-record.zip) 을 **Customize → Skills** 에 올린다. (계정에 한 번)
2. 트래커 과목 화면 → **과목 정보 내보내기** 로 과목·블록 이름을 복사해서, 공부하는 채팅에서
   "기억해: 학습 트래커의 과목 '통계'의 블록 이름은 … 이야" 라고 메모리에 넣는다.
   claude.ai 가 트래커와 **똑같은 이름**을 쓰게 하기 위해서다. (블록이 늘면 다시)

이제 어느 채팅에서 공부하든 "오늘 하루치 공부한 내용 기록 남겨줘!" 하면 된다.
답에 나온 코드블록의 복사 버튼으로 통째로 복사한다.

## claude.ai 에 하는 말 모음

스킬이 알아듣는 요청들이다. 문장이 조금 달라도 된다.

| 하고 싶은 것 | 공부하던 채팅에서 |
|---|---|
| 오늘 기록 | "오늘 하루치 공부한 내용 기록 남겨줘!" |
| 이름을 같이 알려 주며 | "통계 Week 5로 오늘 기록 남겨줘" |
| 다른 날짜로 | "어제 공부한 거 기록 남겨줘" (날짜를 바꿔서 적어 준다) |
| 블록 정보만 고치기 | 트래커의 ⟳ 표시로 복사한 텍스트를 붙여넣고 "블록 정보 갱신해줘" |
| 스킬이 안 잡힐 때 | "learning-tracker-record 스킬로 오늘 기록 남겨줘" |

- 답은 코드블록 하나로 온다. 코드블록 오른쪽 위의 **복사 버튼**을 쓰면 된다.
  답 전체를 드래그해 복사해도 트래커가 알아서 읽는다.
- claude.ai 가 과목·블록 이름이나 오늘 날짜를 모르면 기록을 내기 전에 먼저 묻는다. 대답해 주면 된다.

### 블록 정보·과목 정보는 '적힌 항목만' 바뀐다

기록과 함께 오는 블록 정보(---BLOCK---)와 과목 정보(---SUBJECT---)는 **적혀 있는 항목만** 트래커에 반영된다.

- 공부하던 채팅은 트래커에 저장된 다이어그램을 본 적이 없으니 보통 다이어그램을 적지 않는다
  → 트래커의 다이어그램은 **그대로 남는다.**
- 다이어그램의 단계 문구('정독 중' → '완료')를 바꾸고 싶은 날에는, 블록 화면의 ⟳ 표시
  (또는 **블록 정보 내보내기**)로 지금 블록 정보를 복사해 채팅에 붙여넣고 "블록 정보 갱신해줘"라고 한다.
  그 채팅이 지금 다이어그램을 보고 고쳐서 다시 적어 준다.
- 항목을 비우고 싶으면 `다이어그램: (지움)` 처럼 `(지움)` 이라고 적힌 경우에만 비워진다.
- `설명` 도 선택이다. 빠지면 지금 설명이 그대로 남는다. 설명은 `(지움)` 으로 지울 수 없다 — `설명: (지움)` 은
  오류로 멈추고 아무것도 바뀌지 않는다. 설명을 비우려면 과목/블록 설정 화면에서 직접 지운다.
- `마감: 2026-10-31` 처럼 적으면 마감이 바뀌고, `마감: 없음` 이면 지워진다. 빠지면 그대로다.

### 마감 정하기

과목·블록에 마감일을 둘 수 있다. 목록과 상세 화면에 `D-5` · `D-day` · `D+2(지남)` 으로 보이고,
**지났는데 완료로 표시하지 않은 블록은 빨갛게** 보인다. 완료한 블록은 지난 마감이어도 흐리게만 보인다.
(과목에는 완료 체크가 없어서, 블록이 전부 완료돼야 빨간 표시가 사라진다. 블록이 하나도 없는 과목은 지나면 빨갛다)
과목 목록·블록 목록 오른쪽 위의 **마감일순** 으로 급한 순서대로 볼 수 있다.

- **캘린더**: 마감이 있는 날은 칸 오른쪽 위에 `⚑` (여러 개면 `⚑2`)가 붙는다. 마우스를 올리면 무엇의 마감인지
  보이고, 누르면 그날 화면의 **이 날 마감** 에 나온다. 지났는데 끝나지 않은 것이 있으면 빨갛다.
- **홈의 마감 일정** (캘린더 아래): 아직 끝나지 않은 마감 중 지난 것 전부 + 앞으로 30일 이내를
  **지났는데 미완료 / 이번 주 / 다음 주 / 그 이후** 로 묶어 보여준다. 처음엔 5개만 보이고
  **전체 보기** 로 그 자리에서 펼친다. 완료로 표시한 블록은 빠진다. 마감이 없으면 섹션이 보이지 않는다.

- 하나씩: 과목 설정 / 블록 설정의 **마감일** 칸.
- 한 번에: 과목 화면 **과목 전체 가져오기** 에 블록마다 세 줄짜리 블록 정보를 붙여넣는다.
  설명·진행률·그림은 건드리지 않고 마감만 바뀐다.

  ```
  ---BLOCK---
  과목: 통계
  블록: Week 1
  마감: 2026-10-10
  ---END---

  ---BLOCK---
  과목: 통계
  블록: Week 2
  마감: 2026-10-17
  ---END---
  ```

  과목 마감도 같은 방식이다: `과목: 통계` / `마감: 2026-12-20` 두 줄짜리 ---SUBJECT--- 를 **과목 정보 가져오기** 에
  붙여넣으면 과목 설명·그림·블록은 그대로 두고 마감만 바뀐다.

  날짜는 반드시 `YYYY-MM-DD` 다. `2026-13-45` 처럼 없는 날짜나 `10월 10일` 은 오류로 멈추고 아무것도 바뀌지 않는다.

## 미리보기 읽는 법

**읽기** 를 누르면 반영하기 전에 무엇이 들어갈지 보여준다. 반영은 그다음에 누른다.

- **빨간 상자 (가져오지 못했습니다)** — 멈춘 것이다. 아무것도 바뀌지 않았다.
  가장 흔한 원인은 과목 이름이 트래커와 다른 경우다. claude.ai 에 "과목 이름을 ○○로 고쳐서 다시"
  라고 하거나, 붙여넣은 텍스트에서 직접 고친 뒤 다시 **읽기**.
- **노란 상자 (경고)** — 반영은 되지만 확인할 것이 있다.

| 경고 | 할 일 |
|---|---|
| **새로 생성됨: 과목 / 블록** | 정말 새 블록(다음 주차 시작)이면 그대로 반영. 오타라면 취소하고 이름을 고친다 |
| 맞춰 읽었습니다 | 공백·대소문자만 다른 이름을 같은 것으로 읽었다. 그대로 반영해도 된다 |
| 블록 정보가 없습니다 | claude.ai 가 BLOCK 을 안 냈다. 기록만 들어간다 |
| 진행률이 없어 그대로 둡니다 | 블록 정보에 진행률이 빠졌다. 그대로 반영해도 된다 (블록 화면 숫자는 최근 기록 값) |
| '(지움)'으로 적어 ○○이 지워집니다 | claude.ai 가 그 항목을 비우라고 했다. 의도가 아니면 취소 |
| (오류) 설명은 '(지움)' 으로 지울 수 없습니다 | 아무것도 바뀌지 않았다. 설명을 지우려면 설정 화면에서 직접 지운다 |
| 진행률이 다릅니다 | 블록 진행률과 기록 진행률이 다르다. 대개 claude.ai 의 실수다 |
| 날짜가 오늘이 아닙니다 | claude.ai 가 날짜를 잘못 알았을 수 있다. 어제 공부를 오늘 기록하는 거라면 그대로 반영 |

그 아래에는 들어갈 기록 목록(**추가** / **갱신**)과, 블록 정보가 항목별로 어떻게 바뀌는지가 나온다.

## 다시 보기

### 홈

- **오늘의 복습** — 1·3·7·14일 전 기록의 '헷갈렸던 부분 정리' 표에서 3개를 골라 보여준다.
  **정답 요약 보기** 를 눌러 확인하고, 질문을 누르면 원래 기록의 그 줄로 간다.
  같은 날에는 몇 번을 열어도 같은 문제가 나온다. 따로 체크할 것은 없다.
- **캘린더** — 날짜 칸에 그날 기록의 제목이 과목 색으로 붙는다. 제목을 누르면 그 기록으로,
  칸의 빈 곳을 누르면 그날 기록 목록으로 간다.

### 검색 (사이드바, `/` 키)

검색어를 넣으면 맨 위에 **헷갈림 행** 결과가 나온다 — 기록 안의 '헷갈렸던 부분 정리' 표를
한 줄씩 찾은 것이다. 누르면 그 기록을 열고 그 줄을 노랗게 잠깐 표시한다.
그 아래는 과목·블록·기록 결과다.

### 블록 화면

- **블록 진행률** — 가장 최근 기록의 진행률이 그대로 표시된다. 트래커가 계산하는 숫자가 아니다.
- 기록 목록의 **▼** — 직전 기록보다 진행률이 낮아진 기록이다. 오류는 아니고 확인용이다.
- **⟳ 블록 정보가 기록보다 오래됨** — 기록은 쌓였는데 블록 설명·진행률이 갱신되지 않았다는 뜻이다.
  누르면 갱신 요청문(지금 블록 설명·다이어그램 + 최근 기록 3개)이 복사된다. 공부하던 채팅에 붙여넣고
  받은 답을 **오늘 기록 붙여넣기** 에 넣으면 사라진다. 매일 기록과 함께 블록 정보가 오면 거의 뜨지 않는다.
  (블록 정보를 한 번도 받은 적 없는 블록에는 처음에 다 떠 있다)

## 가끔 하는 일

| 하고 싶은 것 | 방법 |
|---|---|
| 블록을 다 끝냈다 | 블록 화면 → **완료로 표시**. 과목 진도율이 올라간다 |
| 새 블록을 미리 만들어 두기 | 과목 화면 → **+ 블록 추가**, 또는 오늘 기록에 새 블록 이름이 오면 자동으로 생긴다 |
| 기록이 엉뚱한 블록에 들어갔다 | 기록 화면 → **수정** → 과목·블록을 바꾸고 저장 |
| 기록 내용을 고치고 싶다 | 기록 화면 → **수정**. 저장은 버튼이나 `Ctrl`+`Enter` (태그 칸의 `Enter` 는 태그만 추가한다) |
| claude.ai 없이 짧게 메모 | 홈 → **+ 직접 쓰기** |
| 새 과목 시작 | [처음 한 번](#처음-한-번)을 그 과목에 대해 한 번 더 |
| 블록을 다른 과목으로 옮기기 | 블록 화면 → **블록 설정** → 소속 과목 |

## 공용 PC에서 쓸 때

기록은 **그 브라우저 안에만** 저장된다. 서버가 없다. PC가 초기화되면 기록도 사라지므로,
백업 파일(JSON)을 들고 다닌다.

**시작할 때**

1. 주소로 접속한다. 설치할 것은 없다.
2. 상단 **⬆ 불러오기** → 가장 최근 `learning-tracker-backup-*.json` 파일.
   - 빈 브라우저면 바로 들어온다.
   - 기록이 남아 있으면 **병합 / 덮어쓰기** 를 묻는다. 헷갈리면 **병합** (기존 기록이 사라지지 않는다).

**끝낼 때**

1. 상단 **⬇ 내보내기** → 받은 파일을 **본인 저장소**(개인 클라우드, 메일 등)로 옮긴다.
   상단에 `내보내기 필요` 가 떠 있으면 아직 안 한 것이다.
2. 다운로드 폴더의 백업 파일을 지운다. 기록 전체가 그대로 들어 있는 파일이다.

## 문제가 생기면

**claude.ai 가 기록 형식이 아니라 평범한 요약으로 답했다**
→ 스킬이 안 잡힌 것이다. "learning-tracker-record 스킬로 다시 뽑아줘"라고 한다.
그래도 안 되면 claude.ai **설정 → Capabilities** 에서 Code execution 이 켜져 있는지,
**Customize → Skills** 에서 스킬이 켜져 있는지 확인한다.

**읽기를 눌렀더니 "읽을 수 있는 형식이 없습니다"**
→ `---ENTRY---` 로 시작하는 부분이 복사되지 않았다. 코드블록의 복사 버튼으로 다시 복사한다.

**기록이 하나도 없다**
→ 정상이다. 이 브라우저에서 아직 **불러오기** 를 안 했다.

**"과목을 찾을 수 없습니다" / "과목이 없습니다"**
→ claude.ai 가 쓴 과목 이름이 트래커와 다르다. 트래커의 이름을 claude.ai 메모리에 넣어 두면
([처음 한 번](#claudeai-에-스킬과-이름-넣기)) 다시 생기지 않는다. 메모리는 프로젝트마다 따로라,
공부하는 채팅이 있는 곳에서 넣어야 한다.

**블록이 비슷한 이름으로 하나 더 생겼다**
→ 미리보기의 '새로 생성됨'을 그냥 넘긴 경우다. 잘못 들어간 기록을 **수정** 에서 원래 블록으로 옮기고,
빈 블록은 블록 설정에서 삭제한다.

**불러오기에서 "학습 트래커 백업 파일이 아닙니다"**
→ 다른 JSON 파일을 골랐다. `learning-tracker-backup-` 으로 시작하는 파일인지 확인한다.

**"파일이 일부 손실된 것 같습니다"**
→ 파일이 전송 중 잘렸다. 다른 백업본으로 시도한다. 기존 기록은 그대로다.

**불러오기에서 덮어쓰기를 잘못 눌렀다**
→ 가져오기가 끝나면 뜨는 창의 **가져오기 직전으로 되돌리기** 를 누른다. 그 창을 닫은 뒤에는
되돌릴 수 없으니, 다른 백업 파일로 다시 불러온다.

**두 PC에서 같은 과목을 각각 만들었다**
→ 병합하면 과목이 둘로 나뉜다. 새 과목은 한쪽에서만 만들고, 다른 PC에서는 백업을 불러온 뒤에
기록을 붙여넣는다.
